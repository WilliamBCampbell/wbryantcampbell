# wbryantcampbell.com

Personal portfolio for William B. Campbell, hosted with GitHub Pages.

## Local preview

The site has no build step. From the repository root, start any static file server:

```sh
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Publishing

GitHub Pages can publish the site directly from the root of the `main` branch. The `CNAME` file identifies `wbryantcampbell.com` as the custom domain. The same domain must also be configured under the repository's Pages settings.
